## Big Data con mis palabras
 
Tecnología para la gestión y análisis de cantidades masivas de información (datos), la cuál es tan elevada y variada que necesita que necesita de dicha tecnología especial para el analisis de la inforamción y toma de decisiones sobre la misma.
 
Un ejemplo de big data, sería transacciones de las targetas de crédito, cada compra, cada reintegro, etc crea transacciones que tiene que tratarse en tiempo real para determinar si es lícito. Con el alto volumen de información ( trasacciones) es necesario el big data para nalizar ese volumen al instante y detectar un posible fraude antes de que se domplete la operación.*
 
*Sin embargo, una BBDD de empleados de una compañía anual donde a pesar de haber muchos datos ( imagenemos una empresa de 2000 empleados), no sería big data, se puede tratar con Excel.*
